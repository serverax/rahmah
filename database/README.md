# Database — islamic-ai-mobile-app

تنظيم البيانات على ثلاث طبقات:

1. **محلية على الجهاز** — SQLite/Hive: قرآن، أذكار، تفسير، تفضيلات.
2. **خادمية** — PostgreSQL + pgvector: قاعدة المعرفة الشرعية + سجلات بوابة المساعد.
3. **أصول** — تلاوات صوتية وحركات.

تفاصيل المخطط الكاملة في `docs/DATABASE_DESIGN_AR.md`.

## مجلدات

- `migrations/` — ترحيلات Alembic/Prisma (تُضاف لاحقاً).
- `seeds/` — بذور البيانات (قرآن، أذكار) من مصادر موثقة.
- `knowledge/` — مخطط قاعدة المعرفة الشرعية وتراخيصها.

## خصوصية

- لا نخزّن نص أسئلة المستخدم.
- لا نخزّن معرّفات شخصية.
