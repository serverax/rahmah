# Rahma Design System

## Palette

- Primary: `#0F5D4A`
- Secondary: `#0E7C66`
- Gold: `#D8A441`
- Sand: `#F3E7D0`
- Night: `#071B1A`
- Cream: `#FFF8EA`
- Moon white: `#F8F5EC`
- Calm blue: `#2F80ED`
- Warning red: `#C94C4C`
- Amber: `#E8A928`

## Typography

- Arabic text must be readable and RTL-safe.
- Quran text should be clear and unembellished.
- English text should use a clean sans-serif fallback.
- Avoid tiny text in reader and citation surfaces.

## Spacing

- Base spacing: 8px.
- Card padding: 16px to 24px.
- Screen padding: 18px.
- Section spacing: 22px minimum.

## Card style

- Rounded radius: 24px for main surfaces.
- Use layered gradients and borders.
- Shadows should be soft, not harsh.
- Content cards should feel elevated but not heavy.

## 3D style rules

- Use gradients, shadows, and layered surfaces.
- Add crescents, lanterns, and geometric motifs as light background elements.
- No heavy 3D assets.
- No human figures for religious authority screens.

## Accessibility

- Tap targets must stay large enough for phones.
- High contrast must remain readable.
- Use semantic labels where needed.
- Respect RTL layout in spacing and alignment.

## App store notes

- Do not present AI as a fatwa authority.
- Cite sources when content is approved.
- Clarify privacy and offline behavior.
- Avoid misleading claims about content completeness.
