# Rahma 3D UI/UX Vision

Rahma is a calm, premium Islamic mobile experience. The visual language must feel spiritual, trustworthy, warm, and family-safe.

## Design principles

- Arabic RTL is first-class.
- Quran text is displayed respectfully and never distorted.
- The interface should feel like a companion, not a game.
- 3D means depth, soft gradients, layered cards, and gentle motion.
- Avoid harsh neon, noisy surfaces, and cartoon religious visuals.

## Visual language

- Deep emerald and night tones for calm modes.
- Soft cream and sand for light modes.
- Gold is an accent, not a dominant fill.
- Cards use glass-like surfaces, subtle borders, and calm shadows.
- Backgrounds use crescents, mosque silhouettes, lantern hints, and geometric motifs.

## Motion rules

- Use soft card entrance motion.
- Use gentle floating motion for crescent and lantern elements.
- Avoid fast or distracting animation.
- Keep transitions short and responsive on normal Android hardware.

## Islamic content rules

- Never invent Quran, Hadith, or fatwa content.
- Never show technical errors to users.
- Prefer approved local content first.
- Show citations for answers that are allowed to publish.
- Show offline status clearly and honestly.
