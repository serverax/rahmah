# Rahma Screen Map

## Core flow

- Splash
- Onboarding
- Home
- Prayer
- Quran
- Quran reader
- Adhkar and dua
- Ask Sheikh Hasan
- Children game
- Qibla
- Library
- Hadith
- Settings

## Layout intent

- Splash and onboarding set the spiritual tone.
- Home acts as the dashboard with prayer, Quran, and quick actions.
- Prayer and Qibla are utility screens with calm, readable layouts.
- Quran and Quran reader prioritize Arabic legibility.
- Ask Sheikh Hasan emphasizes evidence, review, and citation.
- Children uses softer colors and simple rewards.
- Settings keeps safety and offline status visible.
