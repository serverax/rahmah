# Rahma Improvement Center

Internal-only admin surface for reviewing self-improvement proposals.

## What it shows

- detected issues
- feature proposals
- priority score
- risk score
- anonymised evidence summary
- affected area
- suggested tasks
- approval buttons
- reject button with reason
- audit history

## Workflow

1. Signals are collected from safe aggregate observations.
2. Personal data is redacted.
3. Proposals are generated with deterministic scoring.
4. Human reviewers approve planning or code-generation status.
5. Code changes, deploys, and release decisions remain human-controlled.
