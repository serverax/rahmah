# خارطة الطريق — islamic-ai-mobile-app

> صدقة جارية عن روح الوالد عبدالرازق الشافعي رحمه الله. نرجو منكم الدعاء له ولسائر موتى المسلمين.

## نظرة عامة

العمل مقسوم إلى 21 سبرنتاً (Sprint 0 → 20) موزعة على 5 مراحل كبرى.

| المرحلة | السبرنتات | المخرَج |
|---|---|---|
| 1. التأسيس | 0-1 | بنية مشروع + قشرة تطبيق RTL |
| 2. التجربة الأساسية | 2-4 | شاشة رئيسية 3D + تنقل + FAB المساعد (UI) |
| 3. الوحدات الدينية | 5-12 | الصلاة، القرآن، الأذكار، القبلة، التقويم، رمضان، الزكاة، الخطة |
| 4. الذكاء الآمن | 13-15 | API + قاعدة معرفة + بوابة سلامة |
| 5. الإطلاق المسؤول | 16-20 | الدعاء، التنبيهات، الأوفلاين، QA، Beta |

---

## مراحل تفصيلية

### المرحلة 1 — التأسيس
- **Sprint 0**: بنية المستودع، lint، CI أولية، قوالب.
- **Sprint 1**: قشرة Flutter/RN، RTL، خط عربي، Theme إسلامي.

### المرحلة 2 — التجربة الأساسية
- **Sprint 2**: شاشة رئيسية 3D خفيفة.
- **Sprint 3**: تنقل سفلي + رجوع/منزل.
- **Sprint 4**: FAB الشيخ + bottom sheet (UI فقط).

### المرحلة 3 — الوحدات الدينية
- **Sprint 5**: مواقيت الصلاة + الأذان.
- **Sprint 6**: القرآن الكريم.
- **Sprint 7**: الأذكار + التسبيح.
- **Sprint 8**: القبلة.
- **Sprint 9**: التقويم الهجري.
- **Sprint 10**: رمضان.
- **Sprint 11**: الزكاة.
- **Sprint 12**: خطة العبادة.

### المرحلة 4 — الذكاء الآمن
- **Sprint 13**: backend API + نقطة `POST /api/ibadat/ask`.
- **Sprint 14**: قاعدة معرفة شرعية + embeddings.
- **Sprint 15**: بوابة سلامة الفتوى + ربط المساعد بالـAPI.

### المرحلة 5 — الإطلاق المسؤول
- **Sprint 16**: نظام صدقة جارية + دعاء كامل في الإعدادات.
- **Sprint 17**: نظام التنبيهات الموحد.
- **Sprint 18**: وضع أوفلاين.
- **Sprint 19**: QA + تغطية اختبارات + مراجعة شرعية.
- **Sprint 20**: إعداد إصدار تجريبي مغلق.

---

## معالم خارج الخريطة الأولى (ما بعد البيتا)

- وضع للأطفال (تعليمي).
- بطاقات قراءة جماعية للقرآن (offline).
- لغات إضافية (إنجليزي، أوردو، إندونيسي).
- تكامل صدقات إلكتروني (بمراجعة شرعية وأمنية).
- ويدجت شاشة قفل لمواقيت الصلاة.

---

## التزامات مستدامة

- لا نطلق ميزة "إفتاء" بدون مصادر.
- لا ندّعي أن التطبيق "جاهز" قبل اختبار شامل.
- لا نسرّب أسرارَا في الكود أبداً.
- نلتزم بالتحديث الدوري لقاعدة المعرفة.
