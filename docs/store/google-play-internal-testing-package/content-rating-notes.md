# Content Rating Notes

Expected content profile:

- Religious educational content
- User-submitted questions if backend/API is configured
- No ads
- No gambling
- No explicit sexual content
- No graphic violence
- No active payments or donations

Moderation/safety:

- Public Q&A must show approved items only.
- Sensitive fatwa-like issues should require scholar review.
- Prompt injection and unsupported questions should be refused.

Final answers in Play Console must match the exact release behavior.
