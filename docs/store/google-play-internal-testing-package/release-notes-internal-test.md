# Internal Test Release Notes

Initial internal Android release candidate for Rahma.

Included:

- Arabic-first Islamic learning app shell
- Quran/source-aware learning flows
- Ask Sheikh Hasan educational Q&A flow
- Scholar-review and safe-refusal states
- Privacy/terms local fallback
- Prayer/reminder settings
- Children learning section

Known limitations for internal testers:

- Public HTTPS privacy/support URLs are pending.
- Real-device notification scheduling must be verified.
- Azan audio playback is disabled until a licensed playable asset is approved.
- App is not yet approved by Google Play.
