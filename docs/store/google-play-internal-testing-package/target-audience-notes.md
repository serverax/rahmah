# Target Audience Notes

Recommended declaration:

General audience.

Rahma has a children learning section, but the current release should not be positioned as primarily directed to children unless the full Google Play Families requirements are deliberately completed.

Children safety notes:

- Children should use Rahma with parent/guardian supervision.
- Children should not submit personal information.
- No ads SDK was found.
- External links must be disabled unless verified and appropriate.
- AI/chat features must be guarded and must not give sensitive personal rulings to children.
