# App Description

Rahma / رحمة is an Arabic-first Islamic learning app for families and general users. It provides Quran references, source-aware Islamic Q&A, prayer tools, reviewed answers, and children-friendly learning screens.

Rahma provides educational Islamic information. It is not a formal fatwa authority. Sensitive personal, legal, medical, financial, marriage, divorce, and complex fiqh questions should be referred to qualified scholars.

Answers may be limited by the verified sources available in the app. When a source is unavailable or confidence is low, the app should refuse or require scholar review rather than invent an answer.
