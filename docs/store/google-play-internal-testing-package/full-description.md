# Full Description

Rahma / رحمة is an Arabic-first Islamic education app designed for calm, family-friendly learning.

Features:

- Quran references and reading support
- Ask Sheikh Hasan educational Q&A flow
- Source-aware answers with citations where available
- Scholar-review state for sensitive questions
- Prayer and reminder settings
- Children-friendly learning section
- Privacy and terms available inside the app

Important disclaimer:

Rahma provides educational Islamic information only. It is not a formal fatwa authority and does not replace qualified scholars. Sensitive personal, financial, medical, legal, marriage, divorce, or complex fiqh issues should be taken to qualified scholars.

The app may refuse to answer when verified sources are not available, when confidence is low, or when a question requires scholar review.

Azan audio playback is disabled in this release until a licensed audio asset is verified. Prayer/reminder text functionality must be tested on a real Android device before being promoted in store copy.
