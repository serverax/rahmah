# Deployment — islamic-ai-mobile-app

خطط النشر والـCI/CD والبنية التحتية.

## محاور

- `beta/` — ملاحظات إصدار بيتا، نصوص المتاجر.
- `ci/` — تكوينات GitHub Actions الموسّعة.
- `infra/` — Dockerfiles، Helm charts، Terraform (لاحقاً).

## أسرار

- لا تُخزَّن أسرار في هذا المسار أو أي مسار في المستودع.
- تُحقن من منصات النشر (Cloud secrets manager / GitHub Actions secrets) فقط.

## الحالة

> لا توجد أهداف نشر مفعّلة. الإعداد التجريبي يبدأ Sprint 20 فقط.
