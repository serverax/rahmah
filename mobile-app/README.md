# Mobile App — islamic-ai-mobile-app

تطبيق الجوال الإسلامي. الإطار المقترح: **Flutter** (Dart) لخفة الـ3D والأداء عبر المنصات، أو React Native عند الحاجة.

## ركائز التصميم

- Arabic-first / RTL-first
- Mobile-first
- Calm Islamic UI
- Lightweight 3D عبر Rive/Lottie
- وصول لأي شاشة رئيسية في 1-2 نقرة

## التنقل السفلي

`الرئيسية | الصلاة | القرآن | الأذكار | الشيخ الشافعي`

## أيقونة الشيخ العائمة

FAB أسفل اليسار في كل الشاشات، يفتح bottom sheet للمحادثة، محصور بالعبادات فقط.
