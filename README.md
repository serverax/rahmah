# islamic-ai-mobile-app

> صدقة جارية عن روح الوالد عبدالرازق الشافعي رحمه الله. نرجو منكم الدعاء له ولسائر موتى المسلمين.

تطبيق إسلامي عربي بواجهة RTL وتصميم هادئ خفيف ثلاثي الأبعاد، مع مساعد ديني "اسأل الشيخ الشافعي" محصور في العبادات فقط.

---

## الرؤية

تطبيق جوال إسلامي **عربي أولاً** يجمع العبادات اليومية في تجربة هادئة وسريعة وآمنة دينياً:

- مواقيت الصلاة والأذان
- القرآن الكريم (قراءة، استماع، تفسير، ترجمة)
- اتجاه القبلة
- الأذكار وعداد التسبيح
- التقويم الهجري والمناسبات
- قسم رمضان كامل
- حاسبة الزكاة
- خطة عبادة شخصية
- مساعد ذكي للعبادات فقط

---

## المبادئ الأساسية

| المبدأ | الوصف |
|---|---|
| Arabic-first | كل النصوص بالعربية الفصحى أولاً |
| RTL-first | الواجهة من اليمين إلى اليسار |
| Mobile-first | مصممة للهواتف قبل الأجهزة اللوحية |
| Calm Islamic design | ألوان هادئة، خطوط واضحة، فراغات مريحة |
| Lightweight 3D UI | عناصر ثلاثية الأبعاد خفيفة الأداء |
| Safe assistant | المساعد لا يجيب إلا في العبادات وبمصادر موثقة |
| One/Two taps | الوصول لأي شاشة رئيسية بنقرة أو نقرتين |

---

## الميزات الرئيسية

1. **مواقيت الصلاة** بدقة حسب موقع المستخدم مع تنبيهات الأذان والإقامة.
2. **القرآن الكريم**: قراءة، استماع، تفسير، ترجمة، حفظ آخر موضع قراءة.
3. **الأذان والتنبيهات**: اختيار صوت المؤذن، تنبيه قبل الصلاة، تنبيه الفجر والجمعة.
4. **اتجاه القبلة** ببوصلة دقيقة وسهلة.
5. **الأذكار اليومية** مع عداد تسبيح.
6. **التقويم الهجري** والمناسبات الإسلامية.
7. **قسم رمضان**: إمساكية، سحور، إفطار، ختمة قرآن، دعاء يومي، تتبع الصيام.
8. **اسأل الشيخ الشافعي**: مساعد ديني GPT-like محصور في العبادات فقط.
9. **حاسبة الزكاة**: المال، الذهب، التجارة، الأسهم، العملات، العملات الرقمية.
10. **خطة عبادة شخصية** مع تتبع التقدم.

## الفئات المسموح بها للمساعد

طهارة، صلاة، صيام، زكاة، حج، عمرة، أذكار، قرآن، نوافل، رمضان.

## الفئات المرفوضة

السياسة، الميراث، النزاعات القانونية، الفتاوى الطبية، الزواج والطلاق، النزاعات المالية، وأي شيء خارج العبادات.

إذا لم تتوفر مصادر موثقة:

> "لا أملك جواباً موثقاً لهذا السؤال حالياً. يرجى الرجوع إلى عالم موثوق."
