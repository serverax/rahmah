سياسة الخصوصية | Privacy policy

رحمة تقلّل جمع البيانات، لكنها لا تدّعي عدم جمع أي بيانات. عند تكوين الخادم قد تُرسل الأسئلة والرسائل وخيارات النشر إلى واجهة رحمة لمعالجة الإجابة، المراجعة الشرعية، التدقيق، أو إظهار الإجابات العامة المعتمدة.

الموقع اختياري ويُستخدم لحساب أوقات الصلاة والقبلة عند تفعيله فقط. لا نطلب جهات الاتصال أو الصور أو الميكروفون أو الرسائل أو سجل المكالمات أو معرّف الإعلانات.

لا توجد إعلانات أو SDK تحليلات أو Crash SDK مفعّلة حالياً في التطبيق. قد تُحفظ تفضيلات الأذان والتنبيهات محلياً، وقد يتطلب إرسال التنبيهات رمز إشعارات إذا تم تفعيل push production لاحقاً.

الأطفال يستخدمون رحمة بإشراف ولي الأمر. لا يجوز للأطفال إرسال بيانات شخصية.

رحمة تقدم معلومات إسلامية تعليمية وليست جهة فتوى رسمية. الأسئلة الحساسة أو الشخصية أو المالية أو الطبية أو القانونية أو مسائل الزواج والطلاق والميراث تُحال للمراجعة أو تُرفض عند غياب مصدر موثق.

يمكن طلب حذف البيانات أو الدعم عبر البريد: support@ordinoxai.com
