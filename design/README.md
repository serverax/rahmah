# Design — islamic-ai-mobile-app

نظام التصميم وملفات Figma والأيقونات.

- `figma/` — ملفات Figma (تُضاف لاحقاً).
- `tokens/` — ألوان، خطوط، أبعاد كـJSON.
- `icons/` — أيقونات SVG هادئة بنمط إسلامي.
- `screens/` — نماذج شاشات رئيسية.

راجع `docs/UX_UI_DESIGN_AR.md` لتفاصيل النظام البصري الكاملة.
