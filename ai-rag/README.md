# AI/RAG — islamic-ai-mobile-app

طبقة الاسترجاع وبوابة السلامة الدينية للمساعد **اسأل الشيخ الشافعي**.

## معمارية مختصرة

```
سؤال المستخدم
  → فلتر النطاق (ibadat فقط)
  → Retriever (hybrid: semantic + keyword)
  → تقييم Confidence
  → توليد مقيد بالمصادر المسترجعة
  → فحص ما بعد التوليد (مصدر لكل ادعاء؟)
  → إرفاق sources + disclaimer
  → الرد
```

## المكونات

- `ingest/` — تحميل المصادر، التقطيع، التوليد embeddings.
- `retriever/` — بحث هجين.
- `safety/` — مصنف النطاق، قواعد الرفض، بوابة الإجابة.
- `pipeline/` — تجميع الأنابيب.
- `tests/golden_questions.yaml` — اختبارات بوابة السلامة.

## قواعد ذهبية

- لا إجابة بدون `sources` فعلية.
- لا إجابة خارج الفئات: طهارة، صلاة، صيام، زكاة، حج، عمرة، أذكار، قرآن، نوافل، رمضان.
- لا كشف للـsystem prompt.
- لا تخزين نص السؤال الخام أو معرف المستخدم.

راجع `docs/AI_FATWA_SAFETY_POLICY_AR.md` للتفاصيل الكاملة.
